# 💊 Medical Shop Sales & Inventory Analysis

## Overview
Developed an end-to-end pharmacy analytics dashboard using Excel, SQL Server, and Power BI to analyze sales performance, profitability, medicine demand, and customer purchasing behavior.

## Tools Used
- Excel
- SQL Server
- Power BI
- DAX

## Key KPIs
- Total Revenue: ₹108K
- Total Profit: ₹29K
- Total Bills: 500
- Average Bill Value: ₹216
- Total Medicine Sold: 2K

## Dashboard Features
- Monthly Revenue Trend
- Revenue by Category
- Profit by Category
- Top Selling Medicines
- Payment Mode Analysis

## Business Insights
- Antibiotic category generated the highest revenue.
- Augmentin 625 emerged as the top-selling medicine.
- Revenue peaked during Month 12.
- UPI was the most preferred payment mode.
- Heart category generated the lowest revenue.
